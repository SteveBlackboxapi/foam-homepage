# Foam homepage concept

Chrome-simple marketing page for Foam.

- Search pill on a taupe plaster photograph rotates three queries
- Talent / Work / Pitch boxes
- Staged kit face only — no live roster names

Live (after Pages is enabled): https://steveblackboxapi.github.io/foam-homepage/

## Local

Open `index.html` in this folder.

## Pages

Repo Settings → Pages → Source: **GitHub Actions**.
The workflow in `.github/workflows/pages.yml` publishes the root.

## Assets

Images are SVG wrappers around compact JPEGs so they can live in git without binary upload issues.

- `assets/hero.svg` — taupe plaster wall under the search overlay
- `assets/work-*.svg` — editorial mosaic (cook, run, serum, stove, skin)
- `assets/sam.svg` — staged talent portrait (Sam P.)
- `assets/mark.svg` — Foam mark
